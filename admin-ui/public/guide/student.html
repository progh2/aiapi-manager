    학생 안내서

    선생님이 만들어 준 학교 키로 파이썬 코드나 Codex 앱에서 AI 를 불러 써요. 그림을 보면서 순서대로 따라 하면 돼요.

    준비물

    · 선생님이 등록한 학교 구글 계정
    · 학교 안 인터넷(학교 와이파이·컴퓨터실) — 집이나 구글 코랩(Colab)에서는 연결되지 않아요
    · 파이썬으로 쓸 때는 내 컴퓨터에 설치된 Python 3 (VS Code·주피터도 좋아요)

    1로그인하기

    1. 크롬이나 엣지를 열고 주소를 입력해요 주소창에 http://학교서버주소:3000 을 입력하고 Enter 를 눌러요.
    2. 1 [Google 계정으로 승선] 을 눌러요 작은 창이 뜨면 선생님이 등록한 학교 구글 계정을 골라요.
    3. 내 조종석이 열려요 “○○님의 AI API” 화면이 나오면 성공이에요. 처음이라면 2 안내서 링크로 이 페이지를 다시 열 수 있어요.

    “등록되지 않은 계정” 이라고 나와요 — 다른 구글 계정(개인 계정)으로 로그인했거나, 아직 등록되지 않은 거예요. 오른쪽 위에서 계정을 바꾸거나, 선생님께 내 학교 이메일 주소를 알려 드리세요.

    2내 화면(조종석) 둘러보기

    로그인하면 나만 보는 조종석이 열려요. 여기서 내 키, 남은 예산, 최근 호출 결과를 모두 볼 수 있어요.

    번호무엇인가요?
    1남은 예산 · 지금 쓸 수 있는 키 — 돈이 얼마 남았는지, 지금 수업 시간이라 호출할 수 있는지 한눈에 보여요.
    2접속 안내 — 코드에 넣을 서버 주소(base_url)와 모델 이름, 예제 코드가 있어요. [내 키 넣어 코드 복사]와 [Codex 설정] 버튼도 여기 있어요.
    3내 키 — 가려진 API 키와 쓸 수 있는 모델, 사용 시간, 만료일이 나와요.
    4사용 안내서 — 언제든 이 안내서를 다시 열어요.

    화면을 아래로 내리면 날짜별 사용량 그래프와 최근 호출 표가 있어요(6. 안 될 때에서 자세히 봐요).

    3내 키 보고 복사하기

    API 키는 평소에 sk-••••••••7Q2x 처럼 가려져 있어요. 옆 사람이 화면을 봐도 키가 새지 않게 하려는 거예요.

    1. 1 키 위에 마우스를 올려요 올리고 있는 동안만 진짜 키가 보여요. 마우스를 치우면 다시 가려져요.
    2. 2 터치 화면(태블릿)이라면 눈 버튼을 눌러요 10초 동안 보였다가 저절로 가려져요.
    3. 3 [복사] 를 눌러요 키가 복사돼요. 코드의 api_key="…" 자리에 붙여 넣어요(Ctrl+V, Mac 은 ⌘+V).

    키는 비밀번호와 같아요

    · 친구에게 보내거나 단톡방·블로그에 올리지 않아요. 남이 쓰면 내 예산이 줄고 기록에도 내 키로 남아요.
    · 깃허브(GitHub)에 코드를 올릴 때는 키를 꼭 지워요. 올라간 키는 몇 분 만에 다른 사람에게 발견될 수 있어요.
    · 키가 새어 나간 것 같으면 바로 선생님께 말씀드리세요. 옛 키를 막고 새 키로 바꿔 주세요.

    키를 보거나 복사하면 언제 봤는지가 선생님 화면 기록에 남아요(키 내용은 남지 않아요).

    “선생님이 이 기능 전에 만든 키라 여기서 볼 수 없어요” 가 나와요 — 선생님께 새 키로 교체를 부탁하세요. 교체하면 이 화면에서 바로 보여요(옛 키는 더 이상 쓸 수 없으니 코드에서도 새 키로 바꿔요).

    4파이썬에서 쓰기

    OpenAI 공식 파이썬 라이브러리를 그대로 써요. 다른 점은 서버 주소(base_url)를 학교 AI 서버로 바꾸는 것 하나뿐이에요.

    1. openai 라이브러리를 설치해요 (처음 한 번) Windows 는 PowerShell(시작 메뉴에서 PowerShell 검색), Mac 은 터미널을 열고 입력해요.
      TERMINAL
      pip install openai
      pip 를 찾을 수 없다고 나오면 python -m pip install openai (Mac 은 python3 -m pip install openai) 로 해 보세요.
    2. 조종석에서 3 [내 키 넣어 코드 복사] 를 눌러요 내 키와 모델 이름이 이미 들어간 예제 코드가 복사돼요.
    3. 새 파일 hello_ai.py 에 붙여 넣고 저장해요 복사된 코드는 아래와 같은 모양이에요(키 자리에 진짜 키가 들어 있어요).
      PYTHON
      from openai import OpenAI

client = OpenAI(
    api_key="여기에_내_키",
    base_url="__PROXY__",
)
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "안녕하세요!"}],
)
print(resp.choices[0].message.content)
    4. 실행해요
      TERMINAL
      python hello_ai.py
      AI 의 대답이 출력되면 성공이에요! 🎉 조종석의 최근 호출 표에도 방금 호출이 “성공”으로 나와요.

    모델 이름은 내 키 카드의 쓸 수 있는 모델 중 하나를 그대로 써야 해요. 다른 이름을 쓰면 “허용 안 된 모델” 로 막혀요.

    한 걸음 더 ① 계속 대화하기

    질문과 답을 messages 에 쌓아 보내면 AI 가 앞 대화를 기억해요. 빈 줄을 입력하면 끝나요.

    PYTHON
    from openai import OpenAI

client = OpenAI(api_key="여기에_내_키", base_url="__PROXY__")
messages = [{"role": "system", "content": "너는 친절한 파이썬 선생님이야. 짧게 답해."}]

while True:
    question = input("나: ")
    if not question:
        break
    messages.append({"role": "user", "content": question})
    resp = client.chat.completions.create(model="gpt-4o-mini", messages=messages)
    answer = resp.choices[0].message.content
    print("AI:", answer)
    messages.append({"role": "assistant", "content": answer})

    대화가 길어질수록 앞 대화를 매번 다시 보내서 토큰(예산)을 점점 더 많이 써요. 주제가 바뀌면 프로그램을 다시 시작하세요.

    한 걸음 더 ② 키를 코드 밖에 두기

    코드를 친구에게 보여 주거나 깃허브에 올릴 일이 있다면, 키를 코드에 쓰지 말고 환경 변수에 넣어 두세요.

    POWERSHELL
    $env:AIAPI_KEY = "여기에_내_키"
python hello_ai.py
    TERMINAL
    export AIAPI_KEY="여기에_내_키"
python3 hello_ai.py
    PYTHON
    import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AIAPI_KEY"], base_url="__PROXY__")

    이렇게 넣은 환경 변수는 그 PowerShell·터미널 창을 닫으면 사라져요. 창을 새로 열면 다시 넣어요.

    5Codex 앱에서 쓰기

    Codex 는 OpenAI 가 만든 코딩 도우미예요(데스크탑 앱과 터미널용 Codex CLI). 원래는 OpenAI 계정으로 쓰지만, 설정 파일 두 개를 만들면 학교 키로 쓸 수 있어요. 조종석의 [Codex 설정] 버튼이 그 파일을 만드는 명령을 대신 써 줘요.

    Codex 의 “API 키로 로그인” 칸에 학교 키를 넣으면 안 돼요. 그 칸은 OpenAI 서버로 바로 가기 때문에 학교 키를 몰라서 거절돼요. 아래 순서대로 학교 서버 주소를 알려 줘야 해요.

    1. Codex 앱이 깔려 있는지 확인해요 깔려 있지 않다면 선생님 안내에 따라 먼저 설치해요. 설치 후 한 번 켰다가 꺼 두세요.
    2. 조종석의 [Codex 설정] 을 눌러요 접속 안내 칸에 있어요(4번 그림의 4).
    3. 1 쓸 키, 2 모델, 3 내 컴퓨터(Windows/Mac) 를 골라요
    4. 4 [명령 복사] 를 눌러요 화면에는 키가 가려져 보이지만, 복사된 명령에는 진짜 키가 들어 있어요.
    5. PowerShell 또는 터미널을 열어요
      키보드의 Win 키를 누르고 PowerShell 을 입력해 Enter. 관리자 권한은 필요 없어요.
      ⌘+Space 를 누르고 터미널 을 입력해 Enter.
    6. 붙여 넣고 Enter 를 눌러요 Windows 는 마우스 오른쪽 클릭이나 Ctrl+V, Mac 은 ⌘+V. 여러 줄을 붙여 넣는다는 경고가 나오면 그래도 붙여넣기를 골라요. Codex settings saved. Restart the Codex app. 이 보이면 성공이에요.
    7. Codex 앱을 완전히 끄고 다시 켜요 창만 닫지 말고 완전히 종료해요(Windows 는 작업 표시줄 아이콘 오른쪽 클릭 → 종료, Mac 은 ⌘+Q). 새 작업에서 “안녕” 하고 보내 보세요. 답이 오고 조종석 최근 호출에 기록이 생기면 끝!

    터미널용 Codex CLI(codex 명령)도 같은 설정 파일을 써요. 앱이 잘 안 될 때 터미널에서 codex 로 먼저 확인해 보면 원인을 찾기 쉬워요.

    명령 대신 파일을 직접 만들고 싶다면

    설정 폴더에 아래 두 파일을 만들어요. 폴더는 Windows 는 C:\Users\내이름\.codex, Mac 은 ~/.codex 예요(없으면 만들어요).

    config.toml
    # AIAPI (school AI API) - Codex sends requests to the school proxy
model = "gpt-4o-mini"
model_provider = "school"

[model_providers.school]
name = "AIAPI school"
base_url = "__BASE__"
env_key = "AIAPI_KEY"
wire_api = "responses"
    .env
    AIAPI_KEY=여기에_내_키
    • model 은 내 키 카드의 쓸 수 있는 모델 중 하나로 바꿔요.
    • 메모장으로 저장할 때는 파일 형식: 모든 파일을 골라야 이름 뒤에 .txt 가 붙지 않아요.
    • 설정 파일에는 한글을 넣지 마세요(파일이 깨져 Codex 가 읽지 못할 수 있어요).

    원래대로 되돌리기

    OpenAI 계정으로 다시 쓰고 싶으면 설정 폴더의 config.toml 을 지우세요. 전에 쓰던 설정이 있었다면 config.toml.bak 으로 남아 있으니 이름을 config.toml 로 바꾸면 돼요.

    Codex 가 안 될 때

    이런 일이 생기면이렇게 해 보세요
    “허용 안 된 모델” · model not allowedconfig.toml 의 model 이 내 키의 쓸 수 있는 모델과 글자 하나까지 같은지 봐요.
    401 · 잘못된 키 · Unauthorized[Codex 설정] 에서 명령을 다시 복사해 실행해요. 직접 만들었다면 .env 에 빈칸이나 따옴표가 없는지 봐요.
    연결할 수 없음 · Connection error학교 와이파이인지 확인해요. 브라우저로 http://학교서버주소:4000 이 열리는지 봐요.
    설정했는데 여전히 OpenAI 로그인만 나와요Codex 를 완전히 끄고 다시 켜요. 그래도 그러면 터미널에서 codex 로 확인하고, 선생님께 화면을 보여 주세요.
    예산이 금방 줄어요Codex 는 한 번 부탁할 때 여러 번 생각하고 파일을 읽느라 토큰을 많이 써요. 부탁을 작고 분명하게 나눠요.

    6호출이 안 될 때

    막힌 호출은 조종석 아래쪽 최근 호출 표에 빨간 이유 로 나와요. 이유를 보고 아래 표대로 해 보세요. 표에 아무것도 없다면 요청이 학교 서버까지 오지도 못한 거예요(아래 연결이 안 될 때).

    표에 나온 이유무슨 뜻이에요?이렇게 해요
    수업 시간대 밖선생님이 정한 사용 시간이 아니에요.내 키 카드의 사용 시간에 다시 해요.
    예산 초과내 키의 돈을 다 썼어요.선생님께 충전을 부탁해요. 예산 리셋이 있으면 그 주기가 지나면 다시 채워져요.
    학급 예산 초과우리 반 전체 예산을 다 썼어요.선생님께 말씀드려요.
    허용 안 된 모델내 키로 쓸 수 없는 모델이에요.코드의 model 을 쓸 수 있는 모델 중 하나로 바꿔요.
    없는 모델 이름모델 이름에 오타가 있어요.철자·대소문자·하이픈(-)을 확인해요.
    잘못된 키키가 틀렸어요. 일부만 복사했거나 빈칸이 끼었어요.[복사] 버튼으로 다시 복사해 붙여 넣어요. 옛 키라면 새 키로 바꿔요.
    만료된 키쓸 수 있는 기간이 끝났어요.선생님께 연장을 부탁해요.
    차단된 키선생님이 키를 막았어요(시험 시간 봉쇄 포함).선생님께 여쭤봐요.
    속도 제한(RPM/TPM)짧은 시간에 너무 많이 불렀어요.1분쯤 쉬었다가 다시 해요. 반복문이라면 time.sleep(2) 를 넣어요.
    입력이 너무 김한 번에 보낸 글이 너무 길어요.글을 줄이거나 나눠서 보내요.
    응답 시간 초과 공급자 서버 오류AI 회사 서버가 바쁘거나 잠깐 문제가 있어요.잠시 뒤 다시 해요. 계속되면 선생님께 알려요.
    공급자 키 한도 소진 공급자 요금 한도학교가 AI 회사에 준비한 금액이 바닥났어요.내 잘못이 아니에요. 선생님께 알려 드려요.

    연결이 안 될 때 (표에 기록이 없을 때)

    • APIConnectionError · Connection error · 오래 기다리다 끝남 → 학교 와이파이에 연결돼 있는지 확인해요. 집·휴대폰 데이터·코랩에서는 안 돼요.
    • base_url 이 http://학교서버주소:4000 과 똑같은지 봐요. http:// 와 :4000 까지 있어야 해요.
    • 브라우저로 위 주소를 열어 보세요. 영어로 된 문서 페이지가 뜨면 서버는 살아 있는 거예요.

    그래도 모르겠으면 최근 호출 표의 이유와 오류 메시지 전체를 사진 찍어 선생님께 보여 주세요. 원인을 훨씬 빨리 찾을 수 있어요.
