    2처음 한 번: 공급자 키 확인

    학생 키는 학교가 등록한 AI 회사 키(공급자 키)로 실제 호출을 보냅니다. 보통 설치할 때 한 번 등록해 두며, 06 공급자에 키가 하나 이상 있어야 학생 키를 만들 수 있어요.

    • 없으면 06 공급자 → [공급자 키 등록]에서 OpenAI 등의 API 키와 한도를 넣습니다.
    • 공급자 키의 한도는 “학교 전체가 이 회사 키로 쓸 수 있는 금액”입니다. 학생 예산을 다 합친 것보다 넉넉하게 두세요.

    3학급 만들고 키 나눠 주기

    05 키 발급 → 학급 일괄 탭에서 명단 전원에게 같은 금액·같은 기간의 키를 한 번에 만듭니다. 명단에 이메일을 넣으면 학생 계정도 함께 등록되어, 학생이 로그인해 자기 키를 직접 보고 복사합니다. 키를 하나하나 나눠 줄 필요가 없어요.

    1. 1 학급/조를 골라요 처음이면 목록의 + 새 학급 만들기를 고르고 이름(예: 3학년A반)을 씁니다.
    2. 2 인당 예산과 기간을 정해요 인당 예산은 학생 한 명이 쓸 수 있는 금액(달러)입니다. 처음에는 적게 시작해 02 사용량을 보며 늘리세요(Codex 를 쓸 학생은 넉넉하게). 만료일은 학기 끝 날짜, 예산 리셋을 “7일마다”로 하면 매주 다시 채워집니다.
    3. 3 공급자 키와 허용 모델을 골라요 학생이 쓸 모델만 켭니다. 비워 두면 기본 모델 하나만 열려요. 사용 시간대를 비우면 학급 시간표를 따릅니다.
    4. 4 명단을 붙여 넣어요 한 줄에 학번,이름,이메일. 엑셀에서 세 칸을 그대로 복사해 붙여 넣어도 됩니다(탭으로 나뉨). [CSV 불러오기]도 됩니다.
      명단 예시
      학번,이름,이메일
20261001,홍길동,hong@school.kr
20261002,김철수,kim@school.kr
    5. 5 [일괄 발급] 을 눌러요 확인 창에서 인원·금액·모델을 보고 [발급]을 누릅니다.

    · 결과 창을 닫아도 괜찮아요. 키는 암호화해 보관되어 학생은 조종석에서, 선생님은 03 키 관리 → 상세에서 다시 볼 수 있습니다(볼 때마다 작업 기록에 남아요).
    · 같은 명단을 다시 넣어도 이미 있는 학생(별칭 학번-이름)은 새로 만들지 않고 계정만 연결합니다. 이메일을 나중에 받았을 때 그대로 다시 넣으면 돼요.

    명단 없이 빠르게 — 특강·캠프처럼 명단이 없으면 캠프 짧은 키 탭(당일 만료되는 키 N개), 한 명만 필요하면 한 명 탭을 씁니다.

    4학생에게 알려 주기

    08 기록 → 학생 접속 안내에 학생에게 알려 줄 주소 두 개가 정리되어 있습니다. [복사]해서 학급 단톡방·클래스룸에 올리거나 [안내문 인쇄]로 나눠 주세요.

    그대로 복사해 보내도 되는 안내문입니다(이 학교 주소가 들어 있어요).

    안내문
    [AI 수업 안내]
1. 학교 와이파이에서 __SITE__ 에 들어가 학교 구글 계정으로 로그인하세요.
2. '내 키' 카드에서 [복사]를 눌러 키를 코드에 붙여 넣으면 됩니다.

    5사용량 보기 · 충전 · 연장

    02 사용량에서 날짜별·학급별 사용 금액과 “이 속도면 언제 예산이 바닥나는지”를 봅니다. 한 학생이나 여러 학생에게 돈을 더 주거나 기간을 늘릴 때는 03 키 관리를 씁니다.

    1. 1 상태 필터로 좁혀요 “예산 소진”, “7일 안 만료”처럼 고르면 해당 키만 남습니다. 검색 칸에 이름·학번을 써도 됩니다.
    2. 2 처리할 키를 체크해요 맨 위 칸을 체크하면 보이는 키가 모두 선택됩니다.
    3. 아래에 나타난 막대에서 할 일을 골라요 3 충전·연장 — 지금 한도에 금액을 더하고, 만료일에 날짜를 더합니다. 4 새 키로 교체 — 옛 키를 막고 같은 이름으로 새 키를 만듭니다(키 유출, 학생 화면에 키가 안 보일 때). 5 일괄 차단 — 잠시 막기. [일괄 해제]로 다시 엽니다.

    반 전체에 똑같이 더 줄 때는 04 학급/조 → 학급 카드의 [전체 충전]이 가장 빠릅니다.

    6수업 시간 · 차단 · 봉쇄

    수업 시간에만 열기

    학급 카드의 [수정]에서 학급 시간표(요일·시각)를 넣으면 그 시간에만 키가 열립니다. 시간 밖의 호출은 학생 화면에 수업 시간대 밖 으로 나옵니다. 키를 만들 때 따로 사용 시간대를 정한 키는 그 시간대를 따릅니다.

    한 명만 막기 — 차단

    03 키 관리에서 그 학생 줄의 [차단]. 다시 열 때는 [해제]. 키가 새어 나갔다면 차단 대신 [새 키](폐기 후 새 키)를 쓰세요. 옛 키는 영영 막히고 학생은 조종석에서 새 키를 봅니다.

    반 전체를 한 번에 막기 — 봉쇄

    시험 시간이나 사고가 났을 때 학급 카드의 [봉쇄]를 누르면 그 반 키가 모두 막힙니다. [봉쇄 해제]를 누르면 봉쇄로 막았던 키만 다시 열리고, 그 전에 따로 차단해 둔 키는 그대로 막혀 있습니다.

    7학생이 “안 돼요” 할 때

    먼저 08 기록 → 실시간 호출에서 [실패]를 누르면 막힌 호출과 이유가 보입니다. 학생 조종석의 최근 호출 표에도 같은 이유가 나옵니다.

    이유선생님이 할 일
    예산 초과03 키 관리 → 상세 → 충전. 자주 그러면 예산 리셋(7일마다 등)을 켭니다.
    학급 예산 초과04 학급/조 → [수정]에서 학급 예산을 늘립니다.
    수업 시간대 밖지금이 수업 시간이 맞다면 04 학급 시간표나 키의 사용 시간대를 고칩니다.
    허용 안 된 모델학생 코드의 모델 이름을 확인하고, 필요하면 키 [수정](또는 학급 수정)에서 그 모델을 켭니다.
    만료된 키상세 → 연장(기존 만료일에 날짜 더하기).
    차단된 키03에서 [해제], 봉쇄 중이면 04에서 [봉쇄 해제].
    잘못된 키학생이 키를 잘못 붙였거나 교체 전 옛 키를 씁니다. 조종석에서 [복사]로 다시 붙이게 합니다.
    공급자 키 한도 소진06 공급자에서 그 회사 키의 한도를 늘립니다.
    공급자 요금 한도 공급자 키 인증 실패AI 회사 쪽 결제 잔액·키 상태를 회사 관리 페이지에서 확인합니다.
    속도 제한(RPM/TPM)반복문으로 너무 빨리 부르는 중입니다. 학생에게 천천히 하게 하거나 키의 RPM/TPM 을 늘립니다.

    학생 화면에 키가 안 보여요

    이 기능이 생기기 전에 만든 키는 원문이 보관되어 있지 않아 학생 화면에 보이지 않습니다. 03 키 관리 → 상태 “학생 화면에 안 보이는 키”로 골라 모두 체크하고 [새 키로 교체]를 누르세요. 학생에게는 “조종석에서 새 키를 복사해 바꿔 넣으라”고 알립니다.

    로그인이 안 돼요 (“등록되지 않은 계정”)

    07 사용자에 그 학생의 이메일이 있는지 봅니다. 없으면 [사용자 등록]에서 구글 이메일을 넣고 키를 연결하거나, 이메일을 넣은 명단으로 다시 일괄 발급합니다. 학생이 개인 계정으로 로그인한 경우도 많아요.

    Codex 에서 안 돼요

    학생 안내서의 5. Codex 앱에서 쓰기를 보여 주세요. 가장 흔한 실수는 Codex 의 “API 키로 로그인” 칸에 학교 키를 넣는 것입니다. 조종석의 [Codex 설정]이 만든 명령을 실행해야 학교 서버로 연결됩니다.

    8AI 엘피 연결

    오른쪽 아래의 도우미 엘피에게 “3학년A반 소진된 키에 2달러씩 충전해 줘”처럼 말하면, 엘피가 상황을 살펴 제안 카드를 만듭니다. 카드의 [실행]을 눌러야 실제로 바뀌므로 안심하고 물어봐도 됩니다.

    1. 2 모델 연결에서 방식을 골라요 학교 PC 의 Ollama(학교 밖으로 나가지 않음) 또는 ChatGPT(OpenAI API 키) 중 하나를 고르고 주소·키·모델을 넣은 뒤 [저장]합니다.
    2. 1 [연결 시험] 을 눌러 확인해요 엘피 상태의 마지막 시험이 “도구 호출 가능”이면 준비 끝입니다. “대화만 가능”이면 엘피가 화면 정보를 읽지 못하니 도구 호출을 지원하는 다른 모델을 고르세요.
    3. 3 규칙을 정해요 “등록 사용자(학생)도 엘피에게 물어볼 수 있게”를 켜면 학생 조종석에도 엘피가 나타나 자기 키 상황만 알려 줍니다. 외부 서비스로 보낼 때 학생 이름을 가리는 설정도 여기 있어요.

    9관리: 관리자 추가 · 자동 업데이트 · 백업

    이 절은 서버(NAS)를 설치·관리하는 선생님용입니다. 아래 명령은 시놀로지 NAS 에 SSH 로 접속해 실행합니다(설치 폴더가 /volume1/docker/aiapi-manager 인 경우).

    관리자 추가하기

    관리자는 화면이나 Firebase 가 아니라 서버의 .env 파일에 적힌 ADMIN_EMAILS 로 정해집니다. 쉼표로 여러 명을 적을 수 있어요.

    1. .env 를 열어 이메일을 더해요 DSM File Station에서 docker/aiapi-manager/.env 를 텍스트 편집기로 열거나 SSH 에서 sudo vi .env.
      .env
      ADMIN_EMAILS=teacher1@school.kr,teacher2@school.kr
    2. 관리 화면을 다시 만들어요 다시 시작(restart)만 하면 새 값을 읽지 않으니 꼭 아래 명령으로 합니다.
      NAS · SSH
      cd /volume1/docker/aiapi-manager
sudo docker-compose up -d --force-recreate admin-ui
sudo docker exec aiapi-admin-ui printenv ADMIN_EMAILS
      마지막 줄에 새 이메일이 보이면 됩니다. 추가된 선생님은 로그아웃했다가 다시 로그인합니다.

    자동 업데이트 확인

    설치 담당자가 자동 업데이트를 켜 두었다면 NAS 가 10분마다 새 버전을 확인해 스스로 적용합니다. 08 기록 → 시스템 상태의 자동 업데이트 줄에서 마지막 확인 시각과 결과를 볼 수 있어요. 켜는 방법은 저장소 README 의 “자동 업데이트 (NAS)” 절에 화면 순서대로 있습니다.

    로그인해서 조종석에서 다시 복사하면 됩니다. 이메일이 연결되지 않은 학생이라면 03 키 관리 → 상세에서 키를 보고 알려 주세요(작업 기록에 남아요).

    키가 단톡방에 올라갔어요.

    03 키 관리에서 그 키의 [새 키](폐기 후 새 키)를 누르세요. 옛 키는 바로 막히고, 학생은 조종석에서 새 키를 봅니다.

    비용이 얼마나 드나요?

    모델과 질문 길이에 따라 다릅니다. 작은 모델로 짧게 묻고 답하면 한 번에 0.001달러도 들지 않지만, Codex 처럼 파일을 읽고 여러 번 생각하는 도구는 훨씬 많이 씁니다. 02 사용량에서 실제 금액과 소진 예상을 보며 예산을 정하세요.

    집에서도 쓸 수 있나요?

    아니요. 학교 내부망 전용으로 설치되어 학교 와이파이·컴퓨터실에서만 연결됩니다. 구글 코랩(Colab)도 학교 밖 컴퓨터라 연결되지 않습니다.

    다른 선생님에게 관리 권한 없이 반 학생 사용량만 보여 주고 싶어요.

    07 사용자에서 그 선생님 계정을 등록하고 반 학생 키를 연결하면, 그 선생님은 조종석에서 연결된 키의 사용량과 최근 호출을 봅니다. 관리 권한이 필요하면 관리자 추가를 따르세요.

    4000번 포트 주소를 열면 영어 문서가 나와요.

    학생 코드가 접속하는 AI 서버(LiteLLM)의 자동 문서입니다. 꺼서는 안 되지만 그 화면에서 할 일은 없습니다. 관리는 모두 관제 함교(3000번)에서 합니다.

    3D 화면이 느려요.

    오른쪽 위의 정육면체 버튼이나 단축키 T로 3D 관제도를 끄면 가벼워집니다. 기능은 그대로입니다.
