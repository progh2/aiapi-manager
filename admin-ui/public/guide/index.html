AI 회사 (OpenAI 등)답을 만들어
돌려줘요

학생은 AI 회사 계정이나 카드가 없어도 돼요. 선생님이 만든 학교 키 하나로 정해진 예산 안에서 써요. 요청이 막히면 막힌 이유가 기록에 남아서 학생도 선생님도 바로 확인할 수 있어요.

주소 두 개만 기억하세요

· 로그인하는 화면(관제 함교) — http://학교서버주소:3000
· 코드가 질문을 보내는 AI 서버(base_url) — http://학교서버주소:4000

학교 안(학교 와이파이·컴퓨터실)에서만 열려요. 집이나 구글 코랩(Colab)에서는 연결되지 않아요.

처음 보는 낱말 풀이

API
프로그램끼리 주고받는 약속이에요. 내 코드가 AI 에게 “이 질문에 답해 줘”라고 부탁하는 창구예요.
API 키
학교 AI 서버에 들어가는 비밀 출입증이에요. sk- 로 시작해요. 비밀번호처럼 나만 써요.
base_url
질문을 보낼 서버 주소예요. 우리는 OpenAI 대신 학교 AI 서버 주소를 넣어요.
모델
답을 만드는 AI 의 이름이에요(예: gpt-4o-mini). 키마다 쓸 수 있는 모델이 정해져 있어요.
토큰
AI 가 글을 세는 단위예요. 한글 한두 글자쯤이 1토큰이에요. 질문과 답이 길수록 토큰을 많이 써요.
예산
키 하나가 쓸 수 있는 돈(달러)이에요. 토큰을 쓸 때마다 조금씩 줄고, 다 쓰면 막혀요.
